# 💫 About Me:
I am Shoaib Shamrez, a Full-Stack Web Developer passionate about building modern, responsive web applications. I specialize in the MERN stack, React.js, Node.js, TailwindCSS, Material UI, Ant Design, Typescript, React-Bootstrap and MySQL. I have worked on projects ranging from e-commerce platforms, Learning Management System (LMS), Point of Sale (POS) and API-driven applications, and I’m always exploring new ways to turn ideas into clean, scalable, production-ready code.<br><br>In my spare time, I enjoy learning new technologies, contributing to small projects, and refining my coding and UI/UX skills. If you think I can be helpful to your project or idea, feel free to get in touch.
